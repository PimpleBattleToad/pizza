# Неаполитанская пицца — калькулятор теста

Одностраничное приложение: считает тесто для неаполитанской пиццы в граммах,
подбирает дрожжи под ваш график брожения, считает температуру воды и рисует
план на день с часами. Работает офлайн, ставится на телефон как приложение.

Внутри нет сервера и нет интернета: всё считается в браузере, настройки
хранятся в localStorage этого устройства.

---

## Быстрый старт

1. Откройте `pizza.html` двойным щелчком — калькулятор работает сразу, без установки.
2. Поставьте нужные цифры: число пицц, вес шара, гидратацию, соль, режим брожения.
3. Справа сразу видно граммы, температуру воды и план по часам.
4. Нажмите «Скопировать рецепт», чтобы отправить его себе в заметки или в чат.

Ярлык на рабочем столе (Windows): правый клик по `pizza.html` → «Отправить» →
«Рабочий стол (создать ярлык)». В ярлыке можно задать свой значок
(`icons\icon-512.png`).

## Что считает

### Сколько теста

Три способа задать количество — переключатель «Считать»:

| Режим | Что задаёте | Что получаете |
|---|---|---|
| по числу пицц | сколько пицц и вес одного шара | общий вес теста |
| по весу теста | общий вес теста | число шаров |
| по весу муки | сколько муки в пакете | сколько теста выйдет |

Вес шара 250 г — стандарт неаполитанской пиццы ⌀ 30 см. 180–220 г — пицца
поменьше, 280–320 г — большая или с обильной начинкой. Приложение показывает
ориентировочный диаметр шара: `⌀ = 30 × √(вес / 250)`.

### Состав

- **Гидратация** — вода в процентах от веса муки. Неаполитанская норма 58–63 %.
  Ниже 58 % тесто тугое и рвётся при растяжке, выше 65 % домашней муке 00 уже
  тяжело: тесто липнет и расползается.
- **Соль** — 2,5–3 % от веса муки. Меньше — пресный вкус и слабая клейковина,
  больше — дрожжи работают медленнее и тесто темнеет.

### Брожение

Два режима:

- **при комнатной** — классика: 18–24 ч при 18–20 °C. Дольше 30 ч при комнатной
  температуре тесто начинает киснуть и терять силу.
- **холодильник** — 24–72 ч при 4–6 °C, потом 2–6 ч согревания при комнатной.
  Холод даёт более выраженный вкус и аромат, тесто лучше держит форму.

Приложение считает «пунтату» — время общей ферментации до разделки на шары:
10 % от времени в тепле (1–3 ч), в холодном режиме всегда 1 ч.

### Дрожжи

Галочка «Дрожжи подобрать» подставляет процент под ваш график. Модель простая и
предсказуемая:

```
нагрузка = часы × 2^((температура − 20) / 10)
процент свежих дрожжей = 3,6 / нагрузка     (в пределах 0,02–1,2 %)
```

То есть при +10 °C дрожжи работают вдвое медленнее, при +30 °C — вдвое быстрее,
а константа 3,6 подобрана так, чтобы 24 ч при 20 °C давали привычные 0,15 %
свежих дрожжей.

Тип дрожжей влияет только на пересчёт граммов:

| Тип | Коэффициент | Подсказка |
|---|---|---|
| свежие (прессованные) | 1 | эталон, 1 г ≈ кубик 1 см³ |
| сухие быстродействующие | ÷ 3 | треть от свежих |
| сухие активные | ÷ 2,5 | чуть больше, чем быстродействующих |

Если дрожжей нужно меньше 0,3 г — на весах с шагом 1 г их не отвесить. В этом
случае берите щепотку сухих (≈ 0,3–0,4 г), ювелирные весы или разведите дрожжи
в воде ложкой и отлейте часть.

### Температура воды

Температура воды считается по «температуре теста» (DDT — desired dough
temperature):

```
вода = 3 × DDT − температура муки − температура воздуха − трение замеса
```

Трение: руками ≈ 3 °C, планетарный миксер ≈ 5 °C, спиральный ≈ 7 °C.
Целевая температура теста для неаполитанской — 23 °C. Если вода выходит ниже
4 °C или выше 30 °C, приложение предупредит: слишком холодная вода затормозит
дрожжи, слишком тёплая — перегреет тесто.

### Округление

Мука, вода и соль округляются до целых граммов так, чтобы сумма сходилась с
итогом (расхождение не больше 1 г). Дрожжи — до 0,1 г: 0,2 г и 1 г — это разница
между 24-часовым тестом и трёхчасовым.

## План на день

Внизу страницы — таблица с часами: замес, пунтата, разделка на шары, расстойка,
выпечка. Время считается от поля «Начало замеса». Если план переходит через
полночь, у времени появляется пометка `+1 дн.`.

Печь включать за 45–60 минут до первой пиццы: камень или сталь должны прогреться
на максимуме.

## Открыть на телефоне

### Вариант 1: по Wi-Fi (быстро, без интернета)

На компьютере, в папке проекта:

```
node serve-lan.js 8080
```

или двойной щелчок по `serve-lan.cmd`. Сервер напечатает адрес вида
`http://192.168.1.35:8080/pizza.html` — откройте его на телефоне в той же сети
Wi-Fi. Остановить — `Ctrl+C`.

### Вариант 2: закладка на главный экран

1. Откройте страницу на телефоне (по Wi-Fi или из интернета).
2. Safari: «Поделиться» → «На экран „Домой“». Chrome (Android): меню → «Добавить
   на главный экран».
3. Появится значок пиццы, приложение откроется без адресной строки и будет
   работать офлайн.

### Вариант 3: бесплатный хостинг

**GitHub Pages.** Загрузите файлы в репозиторий, включите Settings → Pages →
Deploy from a branch → `main` / `root`. Через минуту страница доступна по адресу
`https://<логин>.github.io/<репозиторий>/`.

**Netlify Drop.** Откройте <https://app.netlify.com/drop> и перетащите папку
целиком (или `pizza-site.zip`). Адрес выдаётся сразу.

Для обоих вариантов нужен https: только на нём браузер разрешает service worker
и установку приложения.

### Вариант 4: Telegram Mini App

1. Опубликуйте сайт по https (GitHub Pages или Netlify).
2. В @BotFather: `/newapp` → выберите бота → укажите URL страницы.
3. Приложение само подхватит тему Telegram и развернётся на весь экран.

Страница подключает `telegram-web-app.js` и вызывает `ready()` / `expand()`.
Данные пользователя не читаются и никуда не отправляются.

## Файлы проекта

```
pizza.html            калькулятор целиком: разметка, стили, скрипт
index.html            редирект на pizza.html
manifest.json         описание приложения для установки
sw.js                 service worker: офлайн-кэш
icons/                иконки 180, 192, 512 и maskable-512
tools/make-icons.py   отрисовка иконок (Python + Pillow)
tools/make-zip.ps1    сборка pizza-site.zip для хостинга
serve-lan.js          статический сервер для раздачи по Wi-Fi
test-pizza.js         проверки расчётов
test-pizza-render.js  проверки отрисовки (заглушка DOM)
test-pwa.js           проверки манифеста, service worker и сервера
```

### Сборка архива для хостинга

```
powershell -ExecutionPolicy Bypass -File tools\make-zip.ps1
```

Появится `pizza-site.zip` с прямыми слэшами в путях (иначе иконки ломаются на
Linux-хостинге). Его можно перетащить в Netlify Drop как есть.

### Перерисовать иконки

```
python tools\make-icons.py
```

Нужен Pillow (`pip install pillow`). Скрипт перезапишет `icons/icon-180.png`,
`icon-192.png`, `icon-512.png` и `icons/maskable-512.png`.

## Тесты

```
node test-pizza.js          # расчёты: дрожжи, вода, граммы, план
node test-pizza-render.js   # отрисовка на заглушке DOM
node test-pwa.js            # манифест, sw.js, ответы сервера
```

Тесты ничего не устанавливают: `test-pwa.js` поднимает `serve-lan.js` на порту
8097 и проверяет ответы по HTTP.

## Обновление приложения

Service worker кэширует файлы, поэтому после правок старую версию нужно выбить:

1. В `sw.js` поднимите версию кэша: `pizza-v1` → `pizza-v2`. Это главное.
2. На телефоне закройте и откройте приложение (или потяните страницу вниз для
   перезагрузки).

Приложение само удалит старый кэш при активации нового service worker.

## Если что-то не так

- **Поля не меняются / старые цифры** — настройки лежат в localStorage. Очистите
  данные сайта или откройте страницу в приватном окне.
- **Не ставится как приложение** — нужен https (или `localhost`). По `file://`
  установка недоступна, но калькулятор работает.
- **Странные дрожжи** — проверьте режим брожения и температуру: 24 ч в тепле и
  24 ч в холодильнике требуют разного количества.
- **Диагностика вёрстки** — откройте `pizza.html?debug`: внизу появится блок с
  шириной экрана и списком элементов, которые вылезают за край.
